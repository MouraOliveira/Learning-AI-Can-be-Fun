Backpropagation, one step at a time

A network learns by guessing, measuring how wrong it was, and nudging each weight to be a little less wrong. Press Next step and follow the signal forward, then the blame backward.

Step has slope 0 everywhere. Every delta is multiplied by that slope, so every delta becomes 0 and nothing learns. This is why networks trained with backpropagation use smooth functions like sigmoid or tanh, or ReLU.

The delta rule, for each case

Highlighted rules are the ones being used right now. Numbers update live.

Output neuron k: δₖ = (tₖ − oₖ) · g′(zₖ)
Weight update: Δvₖ = η · δₖ · h
Hidden neuron: δₕ = f′(zₕ) · (δ₁v₁ + δ₂v₂)
Weight update: Δw = η · δₕ · x
The hidden neuron has no target of its own. It inherits blame from both outputs, weighted by how strongly it feeds each one.
Biases: Δb = η · δ (same rule with input 1)
