Simulated annealing lab

A hill climber only ever moves downhill, so it settles into the first valley it finds. Simulated annealing sometimes accepts a worse move on purpose, and a falling temperature controls how often. Run it, break it, and see why.

      How it works

      The idea

      Metalworkers anneal steel by heating it and then cooling it slowly. While the metal is hot, its atoms move freely and can leave a poor arrangement. As it cools, they settle into a low-energy one.

      Simulated annealing copies this. The cost of a solution plays the part of energy. The temperature T is a number that says how willing the search is to accept a worse solution.

      The algorithm

      Start from any state with a high temperature. For every step:

      1. Propose a random neighbour of the current state.
      2. Compare: Δ = cost(neighbour) − cost(current).
      3. Probability: p = 1 if Δ ≤ 0, otherwise p = e−Δ/T.
      4. Roll: draw r between 0 and 1. If r < p, move to the neighbour. Otherwise stay.
      5. Cool: lower T using the schedule.

      The numbers match the rows in “What just happened”. Hill climbing is the same loop with p = 0 for every worse move.

      What temperature does

      Take a ridge that is Δ = 3 higher than where the walker stands.

      T = 1074%Nearly random walk
      T = 15%Explores, but prefers low cost

      A useful rule of thumb: the search is active while T is about the size of the ridges it still needs to cross.

      Cooling schedules

      Geometric multiplies T by a fixed factor each step. It is the usual choice. Linear lowers T by a fixed amount. Constant never cools, which is useful for seeing what a single temperature does.

      Cool slowly and the walker keeps its chance to escape for longer. Cool too fast and it freezes in whichever valley it is in, which is often the wrong one.

      Terms

      State
      One candidate solution: a position, or a tour.
      Cost
      How bad a state is. Lower is better. Some books maximise a “value” instead; flip the sign.
      Neighbour
      A state one small change away from the current one.
      Local minimum
      A state whose neighbours are all worse. Hill climbing stops here.
      Global minimum
      The lowest cost anywhere.
      Hill climbing
      Greedy local search: accept only moves that are no worse.

      Strengths and limits

      Annealing is easy to add to any problem where you can score a state and generate neighbours. It has been used for chip layout, timetables and routing.

      It gives no guarantee in a finite time, its results vary from run to run, and it needs tuning of T₀, the schedule and the move size. On a smooth landscape with one valley, plain hill climbing is faster and just as good. Try the “Single bowl” landscape.
