    About this platform

    Learning AI Can be Fun (LAICbF) is a growing collection of interactive virtual laboratories for teaching and learning artificial intelligence. Each laboratory is a self-contained page that runs in your browser, so it can be used in class, as homework, or offline.

    The laboratories and this site were developed with generative AI tools (Claude, by Anthropic), guided by Paulo Moura Oliveira. Instructors and students are encouraged to check the results against theory and to report any problems they find.

    New laboratories are added over time. Interested in feedback control instead? Visit the sister site Learning Control Can be Fun.

    At a glance

    • One page per lab. Each laboratory is a single HTML file.
    • No setup. No installation, account or server needed.
    • Offline friendly. Download the folder and open index.html.
    • Light and dark. Everything follows your system setting.
